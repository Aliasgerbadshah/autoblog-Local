Automate Your Color Workflow: One Script, Any Palette → Tokens, Swatches & README Badges

One script turns four hex codes into CSS variables, Tailwind config, design tokens, a contrast report and README swatches. Python, Node and PHP versions.

🎨 Palette in play — Clay Flare Spectrum · #10002B #240046 #FF006E #00F5D4

Here is a thing I did by hand far too many times: open a palette, copy four hexes, paste them into a CSS file, retype them into tailwind.config.js, retype them again into a tokens file, then paste each one into a contrast checker, then build a swatch table for the README.

Twelve minutes. Per palette. With at least one typo.

So I wrote the script. This post is the script, in three languages, plus the CI job that keeps it honest.

🧮 1 · The only math you need

Everything — contrast grades, "is this text readable", "should the label be black or white" — comes out of relative luminance:

L = 0.2126R + 0.7152G + 0.0722B

…where each channel is linearised, and contrast between two colors is:

\text{ratio} = \frac{L_{\text{lighter}} + 0.05}{L_{\text{darker}} + 0.05}

contrast.py ⌁ 35 lines, no dependencies

def _channel(c: int) -> float:
    s = c / class="t-number">255
    return s / class="t-number">12.92 if s <= class="t-number">0.03928 else ((s + class="t-number">0.055) / class="t-number">1.055) ** class="t-number">2.4


def luminance(hex_code: str) -> float:
    h = hex_code.lstrip("class="t-comment">#")
    r, g, b = (int(h[i:i + class="t-number">2], class="t-number">16) for i in (class="t-number">0, class="t-number">2, class="t-number">4))
    return class="t-number">0.2126 * _channel(r) + class="t-number">0.7152 * _channel(g) + class="t-number">0.0722 * _channel(b)


def contrast(a: str, b: str) -> float:
    la, lb = sorted((luminance(a), luminance(b)), reverse=True)
    return round((la + class="t-number">0.05) / (lb + class="t-number">0.05), class="t-number">2)


def grade(ratio: float) -> str:
    return ("AAA" if ratio >= class="t-number">7 else
            "AA" if ratio >= class="t-number">4.5 else
            "AA Large" if ratio >= class="t-number">3 else "fail")


def readable_ink(bg: str) -> str:
    """Black or white text for any background — the one-liner you keep."""
    return "class="t-color">class="chip" style="background:#000000">#000000" if luminance(bg) > class="t-number">0.42 else "class="t-color">class="chip" style="background:#FFFFFF">#FFFFFF"

>>> contrast("#FF006E", "#10002B"), grade(5.18)
(5.18, 'AA')
>>> readable_ink("#00F5D4")
'#000000'

🖨️ 2 · Emit every format from one list

palette_kit.py ⌁ the generator core

NAMES = ["surface", "primary", "accent", "support"]


def css_vars(name, colors):
    body = "\n".join(f"  --color-{k}: {c};" for k, c in zip(NAMES, colors))
    return f"class="t-comment">/* {name} */\n:root {{\n{body}\n}}"


def tailwind(colors):
    body = "\n".join(f"        {k}: &class="t-comment">#x27;{c}'," for k, c in zip(NAMES, colors))
    return ("module.exports = {\n  theme: { extend: { colors: {\n"
            f"      palette: {{\n{body}\n      }},\n"
            "  } } },\n};")


def tokens(name, slug, colors):
    import json
    return json.dumps({
        "palette": {
            "$description": f"{name} ({slug})",
            **{k: {"$type": "color", "$value": c} for k, c in zip(NAMES, colors)},
        }
    }, indent=class="t-number">2)

🖼️ 3 · The swatch trick that renders everywhere

READMEs, DEV.to posts, GitHub issues, Notion — none of them let you set a background color. All of them render images. So generate the color as an image:

SWATCH = "https:class="t-comment">//placehold.co/{w}x{h}/{hex}/{hex}.png"


def alt(c):
    """Never ship an empty ![]( ) — describe the colour."""
    return f"{color_name(c)} swatch {c}"        class="t-comment"># e.g. "vivid teal swatch #00F5D4"


def band(colors, w=class="t-number">210, h=class="t-number">110):
    """Touching images on one line = a seamless palette bar."""
    return "".join(
        f"![{alt(c)}]({SWATCH.format(w=w, h=h, hex=c.lstrip(&class="t-comment">#x27;#'))})" for c in colors
    )


def table(colors):
    rows = ["| Swatch | HEX | Contrast vs white | Grade |",
            "| :----: | :-- | :---------------- | :---- |"]
    for c in colors:
        r = contrast(c, "class="t-color">class="chip" style="background:#FFFFFF">#FFFFFF")
        rows.append(
            f"| ![{alt(c)}]({SWATCH.format(w=class="t-number">110, h=class="t-number">44, hex=c.lstrip(&class="t-comment">#x27;#'))}) "
            f"| class="t-string">`{c}` | {r}:class="t-number">1 | {grade(r)} |"
        )
    return "\n".join(rows)

Passing the same hex as background and text color hides placehold.co's default size label, leaving a clean block. The alt() helper matters more than it looks: DEV's editor runs an accessibility check and will nag you for every ![]() with empty square brackets, so generate the description instead of typing it 40 times. 🏷️ Prefer shields.io badges? Here's that variant 
BADGE = "https:class="t-comment">//img.shields.io/badge/{label}-{hex}?style=for-the-badge&labelColor={hex}"

def badges(colors):
    return " ".join(
        f"![{c}]({BADGE.format(label=c.lstrip(&class="t-comment">#x27;#'), hex=c.lstrip('#'))})"
        for c in colors
    )

Badges give you the hex printed on the chip; placehold.co gives you a clean block. Use badges in READMEs, blocks in articles.

🟨 4 · The Node version

Same idea, drop it in any JS project as scripts/palette.mjs:

class="t-comment">#!/usr/bin/env node
import { writeFileSync } from &class="t-comment">#x27;node:fs';

const NAMES = [&class="t-comment">#x27;surface', 'primary', 'accent', 'support'];
const hex = (c) => &class="t-comment">#x27;#' + c.replace('#', '').toUpperCase();
const colors = process.argv.slice(class="t-number">2).map(hex);

const lum = (c) => {
  const [r, g, b] = c.slice(class="t-number">1).match(/../g).map((h) => {
    const v = parseInt(h, class="t-number">16) / class="t-number">255;
    return v <= class="t-number">0.03928 ? v / class="t-number">12.92 : ((v + class="t-number">0.055) / class="t-number">1.055) ** class="t-number">2.4;
  });
  return class="t-number">0.2126 * r + class="t-number">0.7152 * g + class="t-number">0.0722 * b;
};

const contrast = (a, b) => {
  const [x, y] = [lum(a), lum(b)].sort((m, n) => n - m);
  return +((x + class="t-number">0.05) / (y + class="t-number">0.05)).toFixed(class="t-number">2);
};

const pairs = NAMES.map((n, i) => [n, colors[i]]).filter(([, v]) => v);

writeFileSync(&class="t-comment">#x27;theme.css',
  class="t-string">`:root {\n${pairs.map(([n, v]) => `  --color-${n}: ${v};class="t-string">`).join('\n')}\n}\n`);

writeFileSync(&class="t-comment">#x27;tokens.json', JSON.stringify(
  Object.fromEntries(pairs.map(([n, v]) => [n, { $type: &class="t-comment">#x27;color', $value: v }])), null, 2));

writeFileSync(&class="t-comment">#x27;swatches.md',
  pairs.map(([, v]) =>
    class="t-string">`![${v}](https://placehold.co/210x110/${v.slice(1)}/${v.slice(1)}.png)`).join(&class="t-comment">#x27;') + '\n');

console.table(pairs.map(([name, value]) => ({
  name, value, onWhite: contrast(value, &class="t-comment">#x27;#FFFFFF'), onBlack: contrast(value, '#000000'),
})));

🐘 5 · The PHP version

For the WordPress / Laravel / plain-PHP crowd, and for build steps that already run on a LAMP box:

<?php
declare(strict_types=class="t-number">1);

function luminance(string $hex): float {
    $hex = ltrim($hex, &class="t-comment">#x27;#');
    [$r, $g, $b] = array_map(
        static function (string $part): float {
            $c = hexdec($part) / class="t-number">255;
            return $c <= class="t-number">0.03928 ? $c / class="t-number">12.92 : (($c + class="t-number">0.055) / class="t-number">1.055) ** class="t-number">2.4;
        },
        str_split($hex, class="t-number">2)
    );
    return class="t-number">0.2126 * $r + class="t-number">0.7152 * $g + class="t-number">0.0722 * $b;
}

function contrast(string $a, string $b): float {
    $l = [luminance($a), luminance($b)];
    rsort($l);
    return round(($l[class="t-number">0] + class="t-number">0.05) / ($l[class="t-number">1] + class="t-number">0.05), class="t-number">2);
}

function cssVars(string $name, array $colors): string {
    $keys = [&class="t-comment">#x27;surface', 'primary', 'accent', 'support'];
    $out  = "class="t-comment">/* {$name} */\n:root {\n";
    foreach ($colors as $i => $hex) {
        $out .= sprintf("  --color-%s: %s;\n", $keys[$i] ?? "extra-{$i}", $hex);
    }
    return $out . "}\n";
}

$palette = [&class="t-comment">#x27;#10002B', '#240046', '#FF006E', '#00F5D4'];
file_put_contents(&class="t-comment">#x27;theme.css', cssVars('Clay Flare Spectrum', $palette));
printf("accent on surface: %.2f:class="t-number">1\n", contrast(&class="t-comment">#x27;#FF006E', '#10002B'));

$ php palette.php
accent on surface: 5.18:1

🤖 6 · Keep it honest in CI

Colors rot. A designer tweaks one token, a junior hardcodes a hex, and six weeks later your "accessible" theme is not. Fail the build instead:

# .github/workflows/contrast.yml
name: contrast

on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: &#x27;3.12'
      - name: Audit theme contrast
        run: python3 tools/palette_kit.py contrast --from-json data/palettes.json
      - name: Fail if any text pair is below AA
        run: python3 tools/audit.py --min 4.5 --pairs data/text-pairs.json

  # data/text-pairs.json — the pairs you actually ship
  [
    { "fg": "#E7E9EE", "bg": "#10002B", "use": "body" },
    { "fg": "#00F5D4", "bg": "#10002B", "use": "links" },
-   { "fg": "#7A5AA8", "bg": "#240046", "use": "labels" },
+   { "fg": "#B9A6E0", "bg": "#240046", "use": "labels" }
  ]

(#7A5AA8 on #240046 is 3.31:1 — a fail for label text. Lightening the violet to #B9A6E0 takes it to 8.25:1.)

🧾 The checklist

  1. Store the palette once, in JSON, with its source URL next to it.
  2. Generate CSS, Tailwind and tokens — never retype a hex.
  3. Generate swatch markdown too; your README should show the colors, not list them.
  4. Compute onWhite / onBlack for every color to decide light vs dark mode roles.
  5. Put a contrast assertion in CI with the pairs you really ship.
  6. Regenerate, don't edit. The script is the source of truth; the artifacts are build output.
