🔑 Persistent Workspace API Key Vault

1. Google Blogger API Integration

🔑 OAuth 2.0 Credentials (Required for Test & Publishing):

Access token is NOT needed — it auto-generates from the Refresh Token.

Setup steps:

  1. Google Cloud Console → Enable Blogger API v3
  2. Google Cloud Console → Credentials → Create OAuth 2.0 Client ID (Web application)
  3. Add Authorized redirect URI: https://developers.google.com/oauthplayground
  4. Copy Client ID + Client Secret → paste below
  5. Go to OAuth Playground → Step 1: select Blogger API v3 → Authorize
  6. Step 2: Click Exchange authorization code for tokens → Copy Refresh Token (starts with 1//)
🔒 Paste the refresh token from OAuth Playground (Step 2). It starts with "1//" and never expires.

🔑 How to Get a Valid Refresh Token

The unauthorized_client error means your Refresh Token was generated with a DIFFERENT Client ID/Secret. Follow these steps exactly:

  1. Google Cloud Console → APIs & Services → Credentials
    Create or find your OAuth 2.0 Client ID (Application type: Web application, NOT Service Account).
    Under Authorized redirect URIs, add: https://developers.google.com/oauthplayground
    Click Save.
  2. Google Cloud Console → APIs & Services → OAuth consent screen
    Make sure the app is Published (not "Testing"). If in Testing, add your Google account as a test user.
    Under Scopes, add: https://www.googleapis.com/auth/blogger
  3. Go to OAuth Playground: https://developers.google.com/oauthplayground
  4. Click the ⚙️ Settings gear icon (top-right)
    ✅ Check "Use your own OAuth credentials"
    Paste YOUR Client ID and Client Secret (the same ones from step 1)
  5. In Step 1 of Playground, paste this scope in the input field:
    https://www.googleapis.com/auth/blogger
    Click "Authorize APIs"
  6. Authorize with your Google account in the popup
  7. In Step 2, click "Exchange authorization code for tokens"
  8. Copy the Refresh token (starts with 1//) and paste it in the Refresh Token field above
  9. Save the vault, then click "Test Blogger Connection"
