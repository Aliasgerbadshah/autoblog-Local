⏰ Daily schedule

Hostinger cron (hPanel → Advanced → Cron Jobs):
0 6 * * * php /home/USERNAME/public_html/backlink-maker/cron/daily.php

Recommended for exact timers + community pacing: one run every 30 min →
*/30 * * * * php /home/USERNAME/public_html/backlink-maker/cron/backlink-30min.php
Use this line instead of the daily one. Each site's own timer (Site Panels) then fires at the exact hour you choose, and "2-3 comments/day" stays bot-safe.
